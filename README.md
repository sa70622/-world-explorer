# World Explorer 🌍

World Explorer is a web application that allows users to explore countries around the world.

## Features

- Browse countries
- Search countries by name
- Filter countries by region
- Sort countries by population and area
- View country details
- Add and remove favorite countries
- Compare two countries
- Save favorites using LocalStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- LocalStorage

## Project Purpose

This project is created to practice JavaScript concepts, API integration, DOM manipulation, and Git & GitHub.
